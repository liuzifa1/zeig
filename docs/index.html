Support

Help for Zeig!, an archive app for iPhone and iPad. Open ZIP, 7z, RAR, tar and many more formats, and create archives, all on your device.

Getting started

  1. Add files on the Browse tab with + › Import from Files…, or put them in On My iPhone › Zeig! in the Files app.
  2. Tap an archive to look inside. Tap a file to preview it, or tap Extract All.
  3. To make an archive, long-press a file or folder and choose Compress.

Opening archives

Zeig! opens ZIP, 7z, RAR, tar and its compressed variants, GZIP, XZ, Zstandard, ISO, DMG, CAB and many more. Formats are recognized by their content, so a missing or wrong extension is fine.

From another app, share an archive and choose Open in Zeig!. It's copied into Zeig!'s folder first.

Creating archives

Pick a format, a compression level and an optional password. ZIP and 7z support passwords. Advanced settings lists more options per format, and the Format Guide in Settings explains each of them.

Troubleshooting

An archive won't open

  • Make sure it finished downloading. A partial file usually reports a damaged archive.
  • Use ⋯ › Test Archive to check whether the data is intact.

Wrong password

  • Passwords are case-sensitive. Zeig! never stores them, so it asks again each time.
  • Some archives encrypt file names too. Those ask for the password before showing anything.

I can't find extracted files

  • Files are extracted into a folder next to the archive, named after it.
  • The same folder appears in the Files app under On My iPhone › Zeig! (On My iPad on iPad).

RAR creation

  • Creating RAR archives is an experimental option, off by default. Turn it on in Settings › Experimental.
  • Zeig! checks every RAR it creates with 7-Zip. Keep your originals until you've checked the archive opens where you need it.

Privacy

Zeig! works offline and doesn't collect, sell, share or track any data. Read the full Privacy Policy.

Contact

Still stuck, or found a bug? Open an issue on GitHub. Include your device model, iOS version, Zeig! version (Settings › App) and what happened. Please don't attach private files.
